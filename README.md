# Type Rush

5問のひらがな短文を入力し、クリアまでの時間を計測するブラウザ向けタイピングゲームです。
85% 以上一致していれば次の問題へ進めます。

- 5問のひらがな短文を、最速でクリアするまでの時間を競います。
- お題は「AIへの指示」でありそうな文が中心（「このぶんをまとめてください」など）。
- 誤字があっても入力は止まりません。不合格ならその場で直して再提出できます。
- 判定は Levenshtein 距離による**暫定的な文字列の近さ**です。AIによる意味理解ではありません。
- 登録・サーバー・APIキーは不要。記録はブラウザの localStorage にのみ保存されます。

仕様の詳細は [docs/SPEC.md](docs/SPEC.md) を参照してください。

## 起動方法

Node.js 20 以上を想定しています。

```bash
npm install
npm run dev      # 開発サーバー（表示された URL を開く）
npm test         # 単体テスト・画面フローのテスト
npm run build    # 本番ビルド（dist/ に静的ファイルを出力）
npm run preview  # ビルド結果をローカルで確認
```

### 静的ホスティング

`npm run build` の出力（`dist/`）はそのまま静的ホスティングに置けます。`vite.config.ts` で `base: './'` を指定しているため、GitHub Pages のプロジェクトページや Cloudflare Pages などのサブパス配信でも動作します。バックエンド・外部通信はありません。

OGP の画像 URL は絶対 URL が求められるため、公開先が決まったら `SITE_URL` を渡してビルドします。

```bash
SITE_URL=https://example.github.io/type-rush npm run build
```

未指定のときは相対 URL のまま出力されます（ローカル確認用）。

アイコンとOGP画像は `public/` にあります。デザインを変えたときは次で再生成できます（Chrome が必要）。

```bash
npm run ogp
```

## 公開

公開用のワークフロー `.github/workflows/deploy.yml` を用意してありますが、
**まだ公開はしていません**。必要なときに手動実行してください。

前提として、次のどちらかを選ぶ必要があります。

- GitHub Pages を使う: private リポジトリでは Pro 以上が必要。無料枠なら public にする。
- Cloudflare Pages などを使う: private リポジトリのまま公開できる。

GitHub Pages で公開する手順:

1. リポジトリを public にする（または Pro に加入する）
2. Settings → Pages → Source を **GitHub Actions** にする
3. Actions → Deploy → Run workflow を実行し、`site_url` に公開URLを入れる
4. 公開URLで動作確認する（初回表示、5問クリア、リロード後のベスト保持）

## 遊び方

1. スタート画面で「スタート」（Enter でも可）。
2. お題が表示され、入力欄に自動でフォーカスします。
3. **最初の確定入力**からタイマーが動きます（IME 変換中は開始しません）。
4. お題を見ながら入力し、Enter で判定します。
5. 合格なら次の問題へ。不合格でも止まらず、入力を直して再提出できます。
6. 5問クリアでタイマーが止まり、結果画面に総時間・速度・平均一致率・自己ベストが表示されます。

キーボードだけで開始・入力・確定・再挑戦まで操作できます。貼り付け・ドロップは拒否されます。

## 出題と難易度

問題は `src/game/problems.ts` に112問あり、すべてひらがな・20〜40文字・重複なしです。
文字数で3つの帯に分かれ、**同じ帯の中だけで5問を選びます**。

| 帯 | 文字数 | 問題数 |
| --- | --- | --- |
| 短め | 20〜21文字 | 38問 |
| ふつう | 22〜26文字 | 30問 |
| 長め | 27文字以上 | 44問 |

スタート画面で帯を選べます（「混ぜる」を選ぶと全体から抽選）。帯を固定すると問題の長さが揃うので、
タイムをそのまま比べられます。

### シード固定と再挑戦

問題セットは**シード**から決まります（`src/game/selection.ts` の mulberry32）。
同じシードと同じ帯なら、必ず同じ5問が同じ順で出ます。

- 結果画面の「**同じ5問でもう一度**」で、終わったのと同じセットを再現して再挑戦できます。
  条件が揃うので、タイムを直接比べられます。
- 「別の問題で」を選ぶと新しいシードで抽選し直します。
- セットのシードは結果画面に表示され、自己ベストにも保存されます。


## 判定仕様（MVP）

判定は `src/game/judge.ts` に集約しています。

- 正解・入力の両方に Unicode NFKC 正規化と前後空白除去を適用します。入力内部の空白は削除しません。
- Levenshtein 距離 `d`、正解長 `n`、入力長 `m` として

  ```
  similarity = 1 - d / max(n, m)
  ```

  を計算します（空文字は 0）。
- **`similarity >= 0.85` かつ `入力長 >= 正解長の 80%`** を合格とします。
- 閾値は `SIMILARITY_THRESHOLD` / `MIN_INPUT_LENGTH_RATIO` として定数化しています。
- ルールを変更した場合は `RULES_VERSION` を上げてください。自己ベストはルールバージョンと問題セットごとに比較されます。

### 限界

この判定は**意味を理解したものではありません**。否定・数値・固有名詞の違いを正しく認識できないため、初期問題ではそれらの誤認が重大になりにくい短文を採用しています。将来 `Judge` インターフェースの実装を差し替えることで AI 判定へ移行できる構造です（`SimilarityJudge` → `AIJudge`）。

## 計測・スコア

- `performance.now()` で「最初の確定入力」から「最終問題の合格」までの実時間を計測します。
- 速度は **確定した入力文字数の合計 / 実時間（秒）** を文字/秒・文字/分で表示します（ローマ字の打鍵数ではありません）。
- 不合格の再提出・修正にかかった時間も総時間に含まれます。
- 途中離脱・リロードは未完了として記録しません。
- 自己ベストは localStorage に、ルールバージョン＋問題セット単位で保存します。

## タイピングレベル（ランク）

結果画面に、速度（文字/秒）だけで決まるランクを表示します。`src/game/rank.ts` に定義しています。
AI 時代の称号として、上から下まで並べています。

| ランク | 英語表記 | 文字/秒の目安 |
| --- | --- | --- |
| **AIの神** | AGI | 6.0 以上 |
| バイブコーダー | Vibe Coder | 4.5 以上 |
| プロンプト職人 | Prompt Engineer | 3.5 以上 |
| 打鍵の達人 | Keyboard Artist | 2.7 以上 |
| バイブ見習い | Vibe Apprentice | 2.0 以上 |
| コピペ職人 | Copy & Paster | 1.5 以上 |
| AI入門者 | Getting Started | 1.5 未満 |

- 誤字は減点しません（速く打ち終えることが目的のため）。
- 閾値はあくまで目安です。`RANKS` の `minCps` を書き換えるだけで調整できます。
- 結果画面には次のランクまでの残り（文字/秒）と進捗バーも表示します。
- ランク名・説明は `src/game/rank.ts` の `label` / `summary` / `tagline` で自由に変えられます。

## デザイン

画面は「伝票（しゅうせい）と判子」を下敷きにしています。打ち込んで送る、判定＝朱の判子が押される、というゲームの内容に合わせた表現です。

- **色**: 紙 `#f0f1ed`、墨 `#151a1e`、罫線 `#c8ccc6`、朱 `#cf3a1a`。朱は「最高位」「不合格」「自己ベスト」など、意味のある場面だけに使います。
- **書体**: 日本語ゴシック 1 ファミリー。等幅は数字（タイム・文字/秒）だけに限定し、装飾ではなく計測値の記号として使います。
- **構造**: カードも影も角丸も使わず、罫線と余白で階層を作ります。お題は画面で最も大きい要素です。
- **動き**: 判定の判子が押される瞬間の 1 つだけ。`prefers-reduced-motion` では停止します。

トークンは `src/index.css` の `@theme` にまとめてあります。配色を変えるならそこの 6 つの値だけで足ります。

## 構成

```
src/
  game/
    judge.ts      判定（Levenshtein / 類似度 / Judge インターフェース）
    engine.ts     ゲーム状態遷移・計測・集計
    problems.ts   出題プール（112問・AIへの指示風の短文中心）
    difficulty.ts 文字数帯（短め/ふつう/長め）の定義
    selection.ts  シード付きの出題選択（同じセットを再現できる）
    ime.ts        IME 変換中 Enter の抑止・貼り付け判定
    storage.ts    自己ベストの保存
    format.ts     表示用フォーマット
    rank.ts       タイピングレベル（ランク）の定義と判定
  components/
    RankBadge.tsx 結果画面の称号と到達段数
    RankLadder.tsx スタート画面の称号一覧
    Stamp.tsx     判定・自己ベストの判子
  screens/        スタート / プレイ / 結果
  test/           単体テスト・画面フローテスト
```

`npm run typecheck` で型チェックのみを実行できます。CI（GitHub Actions）では `npm test` と `npm run build` を実行します。

## テスト

`npm test` で以下を含む 111 件のテストが実行されます。

- 類似度の境界（85% ちょうど・未満、長さ 80% ちょうど・未満）
- 空文字・完全一致・不足入力・余分入力・1文字置換
- IME 変換中の Enter で提出されないこと
- 最初の確定入力までタイマーが進まないこと
- 不合格の修正時間が総時間に含まれること
- 5問クリアでタイマーが止まること
- リロードで初期化され、自己ベストが保持されること
- 貼り付けで進行できないこと
- ランクの境界（各閾値ちょうど・直前・0/NaN）と進捗計算
- 結果画面に「AIの神」などのランクが表示されること
- 問題が100問以上あり、AIへの指示風の文が半数以上あること
- 全問題が文字数帯のどれかに収まり、帯ごとに5問以上あること
- 同じシードから同じ問題セットが再現されること
- 「同じ5問でもう一度」で同じ問題が同じ順で出ること

## スコープ外（MVP）

LLM による意味判定、漢字混じり出題、オンラインランキング、アカウント、バックエンド、音・振動などの演出。
